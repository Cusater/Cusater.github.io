我要将此博客框架开源了

#博客框架#开源

为什么我要开源这个博客框架

说实话，其实我一直都有一个想做开源的想法，但是不知道该做什么。之前这个博客是我自己折腾着玩的，从最开始的纯手写 HTML，到后面加 Python 脚本自动生成页面，再到现在加了搜索、归档、暗黑主题、上下篇导航……改了一版又一版，越用越顺手。

所以我就想着：既然这个框架我自己用起来挺舒服，那不如开源出来，让更多想搭博客但不想折腾复杂框架的人也能直接用。不需要学 Hexo、Hugo 这些工具，不需要装 Node.js、npm，一台装了 Python 的电脑就能跑。

博客框架有什么优点吗？

自动化

当你运行 tools.py 时可以自动创建文章，你并不需要太多的复杂操作。其次当你写完文章后运行 tools.py 输入 2 就能把文章的 HTML 页面渲染出来，并自动添加到首页的文章列表。并且当你觉得一切完好想要推送到 GitHub 时只需要运行 tools.py 并输入 3 即可自动推送到 GitHub（只需完成首次推送配置）。

操作简单

只需要一些你自己的博客内容和一张头像照片（命名为 avatar.jpg）即可。博客框架无需安装 Node.js、npm 等，Python 也无需安装任何第三方库，开箱即用！

零依赖纯静态

  • 构建阶段：只用 Python 标准库（os、re、json、subprocess、datetime），pip install？不存在的。
  • 运行阶段：纯 HTML/CSS/JS，不依赖任何前端框架。部署到 GitHub Pages、Vercel、Netlify、Cloudflare Pages 或者任何静态托管，都行。

设计完成度高

  • 🎨 双主题切换：明亮/暗黑主题，刷新不闪烁（提前同步 localStorage）
  • 📱 响应式：手机、平板、桌面端自适应
  • 🔍 文章搜索：按标题/摘要/标签/日期关键词搜索，结果带高亮
  • 📂 归档页面：按年份分组，新→旧排序
  • 🔗 上下篇导航：文章页底部一键跳转相邻文章
  • 🖨️ 打印友好：打印样式已配置，导出 PDF 干净
  • ⚡ 单页体验：用 Hash 路由实现文章/归档/关于页无刷新切换

技术栈

整套系统就四种语言，没了：

| 阶段 | 语言 | 用途 |
|------|------|------|
| 构建工具 | Python 3 | 解析 Markdown、生成 HTML、自动 Git 部署 |
| 页面结构 | HTML5 | 文章模板 + 首页单页应用 |
| 视觉样式 | CSS3 | CSS 变量驱动主题、响应式、动画 |
| 交互逻辑 | 原生 JavaScript | SPA 路由、搜索、主题切换、归档渲染 |

Markdown 解析器是自研的，支持：标题（#/##/###）、引用（>）、无序/有序列表、代码块（\\\`）、分隔线（---）、粗体、斜体、行内代码、链接、图片。日常写博客完全够用。

目录结构

blog/
├── posts/               # Markdown 文章放这里（文件名：日期-标题.md）
│   └── 2026-08-13-我要将此博客框架开源了.md
├── articles/            # build.py 自动生成的文章 HTML 页面（不要手改）
├── avatar.jpg           # 你的头像（自己替换）
├── build.py             # 构建脚本：posts/ → articles/ + posts-data.js
├── tools.py             # 工具入口：建文章/构建/部署一条龙
├── index.html           # 首页（含 SPA 路由 + 关于页）
├── style.css            # 全站样式
├── posts-data.js        # build.py 自动生成的首页文章数据（不要手改）
└── README.md            # 使用说明

三分钟上手

1. 准备环境

只需要 Python 3.8+，没有其他任何依赖。检查一下：

python --version

2. 替换你的信息

  1. 头像：把 avatar.jpg 换成你自己的照片（保持文件名不变）
  2. 关于页：用 VS Code 打开 index.html，搜索 renderAboutPage，把里面的名字（Cusater）、个人介绍、技能标签改成你自己的
  3. 导航栏：同样在 index.html 里，改 .site-title 的博客标题，以及 nav-github 的链接改成你的 GitHub 主页
  4. 页脚：改 © 2026 Edit by Cusater 为你的名字

3. 写第一篇文章

python tools.py
输入 1 → 创建文章
输入标题、标签（空格分隔）、摘要

脚本会自动在 posts/ 下创建带 front matter 的 Markdown 文件，你直接打开写正文就行。

4. 构建页面

python tools.py
输入 2 → 自动把 posts/ 下所有 md 渲染成 HTML 到 articles/，并更新首页数据

5. 本地预览

最简单的方式：双击 index.html 直接打开，或者在项目根目录启动一个简易 HTTP 服务器：

python -m http.server 8000

然后浏览器访问 http://localhost:8000

6. 部署到 GitHub Pages

首次部署（只需做一次）：

git init
git add .
git commit -m "init blog"
git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库名.git
git push -u origin main

然后在 GitHub 仓库设置 → Pages → Source 选 main 分支 /root 目录，保存。等 1~2 分钟就可以通过 https://你的用户名.github.io/你的仓库名/ 访问了。

后续更新文章，只需两步：

python tools.py → 输入 2（构建）
python tools.py → 输入 3（自动 add + commit + push）

GitHub Pages 会自动更新，不用管。

自定义提示

想换主题色？

打开 style.css，改 :root 里的 --text-accent（默认沉稳蓝 #2c5f7c）和 --bg-accent-soft 就行，暗黑主题对应改 html[data-theme="dark"] 下的同名变量。全站引用这些变量，改一处全生效。

文章链接太多？

style.css 里 .article-body a 可以调颜色和下划线样式。

Markdown 语法不够用？

build.py 里的 render_markdown() 函数可以自己扩展。加表格支持之类的也不复杂。

写在最后

这个框架从构思到现在，前前后后改了不知道多少次。从最开始的"能跑就行"到现在"自己用着舒服"，中间踩了不少坑，但最后结果我挺满意的。

开源出来，希望能帮到那些：

  • 想写博客但不想折腾复杂静态站点生成器的人
  • 不想装一堆 Node.js 依赖的人
  • 想看看纯原生前端怎么做博客的初学者

如果觉得好用，欢迎点个 Star，有问题提 Issue，或者直接 PR。博客这种东西，自己用着舒服最重要。祝大家写作愉快！
